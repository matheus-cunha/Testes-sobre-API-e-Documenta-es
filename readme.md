## Padronização de commits

| <Tipo>    | Descrição | Exemplo |
| :---: | :--- | :--- |
| feat | Quando da adição de um recurso, uma "feature" (funcionalidade) | feat (US01) - Implementação de gráfico SCR |
| fix | Correção de um bug | fix (US07) - Correção filtro UF |
| docs | Atualização de documentação | docs (US07) - Inclusão de diagrama de banco de dados |
| style | Mudança de formatação sem alterar código | style(US15) - Padronização CamelCase das variaveis| 
| refactor | Refatoração do código, sem alterar funcionalidade | refactor (US05) - Refatorado código CRUD de usuários
| test| Adiciona ou modifica testes | test (US11) - Adição de teste unitário na tela de login
| chore | Atualizações menores que não impactam diretamente a funcionalidade do código | chore (US12) - Remoção de comentários do código
